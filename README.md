# Biome Sniffer Mod

Add unique sniffers to every biome in Minecraft Bedrock Edition

## Features

- Adds new types of sniffers to each biome
- Gives sniffers movement and animation
- Makes sniffers sniff with the act

## Requirements

- Minecraft Bedrock Edition 1.21.0 or later

## Installation

1. Download the addon files
2. Place the addon files in your Minecraft Bedrock Edition resource packs and behavior packs folders
3. Enable the addon in your Minecraft Bedrock Edition settings

## Usage

Once installed, new types of sniffers will appear in each biome. They will move around and sniff with the act, adding a new layer of exploration to your Minecraft Bedrock Edition world.

## Configuration

The addon does not have a configuration file. To customize the sniffers, you will need to edit the addon files directly.
